# 시설 등록강좌 연결 검토

검토일: 2026-09-14. 대상: 현재 `main/app/facilities` 구현과 `data`의 시설·강좌 관련 CSV 7개 전체.

## 결론

시설과 강좌의 부분 연결은 가능하다. 가장 넓게 연결되는 자료는 `스포츠강좌이용권 이용현황 정보.csv`다. 다만 이용현황은 과거 이용 이력을 포함하므로 현재 모집·운영 중인 등록강좌 전체라고 표현할 수 없다. 화면에는 자료 기준기간과 출처를 표시해야 한다.

현재 빈 영역은 조회 실패 결과가 아니다. `main/templates/facilities/index.html:19`가 항상 “등록 강좌 연결 자료 없음”을 출력한다. `main/app/facilities/views.py`는 강좌를 조회하거나 템플릿에 전달하지 않으며 `models.py`도 시설 기본정보만 반환한다.

## 점검 방법

- UTF-8-SIG로 전체 파일을 스트리밍 파싱했다. 현재 앱과 동일하게 관대한 CSV 파서를 사용했다.
- 앞뒤·연속 공백과 영문 대소문자만 정규화했다. 주소 개명, 행정코드 변환, 유사 문자열 매칭은 적용하지 않았다.
- 기본 비교 키: 시도코드 + 시군구코드 + 시설명 + 기본주소 + 상세주소.
- 열 수가 헤더와 다른 행은 분석에서 제외했다. 일반 강좌 3행, 청소년·유아동 프로그램 266행이다.
- 기존 `source-inventory.json`에는 엄격한 따옴표 파싱 오류도 기록되어 있다. 이번 수치는 관대한 파서 기준의 연결 가능성 분석이며 원천 데이터 품질 인증이 아니다.
- 일치하는 키는 연결 후보를 뜻한다. 사업자·지점·기준시점까지 검증한 고유 시설 수를 뜻하지 않는다.
- 실행 스크립트: `scripts/inspect_facility_links.py`. 집계 근거: `docs/facility-link-audit.json`.

## 시설 원천의 상태

`스포츠강좌이용권 시설 데이터.csv`는 28,892행이다. `COURSE_NM`과 `COURSE_ITEM_NM` 열은 존재하지만 두 열 모두 전체 행에서 비어 있다. 이 파일만으로 강좌 목록을 만들 수 없다.

시설 비교 키는 28,696개이며 동일 키가 반복되는 그룹은 193개다. 상세주소를 제외하면 후보가 둘 이상인 그룹도 483개다. 현재 `facility-행번호`는 CSV 행 위치에 의존하므로 지속적인 연계 키로 사용하기 전에 안정적인 식별 방식이 필요하다.

일반 이용현황의 정확한 일치 행에서 시설 키+강좌명 조합은 35,300개다. 같은 강좌명이 여러 기간·강좌번호를 가질 수 있으므로 이 값은 고유 강좌 수가 아니다. 일반·장애인 이용현황의 강좌 개설연도는 2020~2026년이며 최대 개설연월은 2026-08이다.

일반 이용현황은 정확한 일치 행 모두 강좌명·강좌번호·금액을 가지고 있고, 시작일·종료일은 각각 437,246행에 있다. 대상·요일·일일 시작/종료시간은 해당 파일의 헤더에 없다.

청소년·유아동 자료의 단일 후보는 관악구민종합체육센터, 은평구민체육센터, 포항실내수영장이다. 예를 들어 관악구민종합체육센터의 코드는 프로그램 원천에서 `1100000000 / 1162000000`, 시설 원천에서 `11 / 11620`이다. 문자열을 그대로 비교하면 연결되지 않는다. 9,902행이 3개 시설에 모여 있으므로 그대로 개별 등록강좌 수로 표시하지 않는다.

일반 강좌 원천은 동일 종목코드+강좌명에 서로 다른 레코드가 존재하는 키가 5,804개다. 장애인 강좌 원천은 1,954개다. 한 시설 후보만 관측된 경우에도 명시적인 외래키가 생긴 것은 아니므로 시간·요일·수강료를 자동 결합하면 안 된다.

## 구현 시 적용할 방식

1. 일반 이용현황을 우선 연결하고 “이용현황 자료에 기록된 강좌”와 기준기간을 표시한다. 시설명 단독 검색을 연계로 취급하지 않는다.
2. 동일 시설의 월별 이력을 모든 강좌로 나열하지 않도록 기간 선택과 강좌 식별 규칙을 정한다. `COURSE_NO`의 범위·재사용 여부를 확인한 뒤 시설·강좌·기간 키를 구성한다. 강좌명만으로 중복 제거하지 않는다.
3. 강좌명·종목·기간·원자료 금액을 표시한다. 금액의 월/회/전체과정 단위는 미확인으로 유지하고, 대상·요일·시간은 별도 검증된 연결이 없으면 미제공으로 표시한다.
4. 청소년·유아동 프로그램은 행정코드 대응을 검증한 뒤 시설명·주소가 명확히 일치하는 범위에서 별도로 연결한다. 이 원천에는 대상·요일·시간대·가격 유형 필드가 있으나 실제 값의 품질과 중복도 확인한다.
5. 일치하지 않거나 후보가 여러 개인 행은 연결 미확인으로 남긴다. 자료 미등장을 실제 강좌 0개로 해석하지 않는다.
6. 전체 CSV를 시설 클릭마다 다시 읽지 않도록 사전 인덱스 또는 캐시를 두고 원천 교체 시 갱신 정책을 정한다.

## 변경 및 검증 범위

분석 스크립트와 JSON 결과, 이 검토 문서만 추가했다. 애플리케이션 코드와 원본 CSV는 수정하지 않았다. 스크립트 전체 실행이 완료되었으며 앱 동작 변경이 없어 Django 테스트·브라우저 검증은 실행하지 않았다. 스냅샷의 현재성·공식 코드체계·강좌번호 의미·가격 단위 검증은 후속 작업이다.
