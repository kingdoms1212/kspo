# Gemini 검토 데모

프로그램 정보 입력에서 `AI 검토 포함`을 선택하면 보고서 하단에 더미 응답을 표시합니다.
외부 API 호출, API 키 사용, 모델 학습, 데이터 전송은 없습니다.
더미 결과임을 화면과 인쇄물에 표시하며 실제 적합성 판단을 하지 않습니다.

## 구성

- `app/ai_review/client.py`: `ReviewClient` 호출 계약, `DummyGeminiClient`, 미구현 `GeminiClient`
- `app/ai_review/services.py`: 입력·보고서 통계로 근거 구성, 응답 구조 검증, 실패 처리
- `dashboard/plan_views.py`: 유효한 계획서에 선택적으로 검토 결과 포함
- `dashboard/_plan_ai_review.html`: 서버 이스케이프를 적용한 결과 표시

현재 더미 호출은 즉시 반환하므로 기존 보고서 생성 요청 안에서 실행합니다.
완성된 HTML을 기존 방식으로 서명하므로 최근 5건 복원·인쇄에도 동일 결과가 포함됩니다.
복원할 때 재검토하거나 CSV를 다시 읽지 않습니다. 선택하지 않으면 호출하지 않습니다.
시설 미지정의 기존 허용 조건을 유지하며, 미지정 결과에는 시설 판단 제한을 표시합니다.
응답 실패·형식 오류에도 기본 보고서는 생성됩니다.

## 실제 연동 시 남은 작업

`ReviewClient.review(evidence)`는 summary, findings(title/status/comment), suggestions,
limitations를 반환합니다. 현재 검증은 길이·필수 항목·상태값을 제한합니다.
입력은 사용자 설계 내용, 선택 시설 정보(연락처 제외), 보고서 통계입니다.
더미 의견은 실제 통계를 평가하지 않습니다. 원본 전체 검색이나 유사 프로그램 검색,
CSV 데이터 세대 추적은 이번 데모 범위에 포함하지 않습니다.

실제 Gemini 연동 때에는 별도 검토 요청 흐름과 시간 제한, 동시 호출 제한, 비용·한도 관리,
프롬프트와 근거 검증, 실제 모델·데이터 세대 기록, 데이터 전송 안내를 추가해야 합니다.
`GeminiClient`는 현재 NotImplementedError를 발생시킵니다. 실제 전송 코드를 여기에만
추가하는 것으로 운영 준비가 끝나는 것은 아닙니다. UI의 데모 안내도 함께 변경해야 합니다.
API 키는 브라우저나 저장 결과에 포함하지 않고 서버 환경변수로 관리해야 합니다.
