## 이미지와 달리 유지한 내용

- 확인된 지도 자산이 없으므로 대한민국 경계나 임의 지도 마커를 그리지 않는다. 지역 선택과 목록은 실제 조회값을 사용한다.
- 실제 시설 사진이 없으므로 공통 건물 아이콘을 표시한다. 공식 기관 로고도 임의 복제하지 않는다.
- 수혜율·대상자당 시설·교통 지표는 검증되지 않았으므로 확인 필요/미연결 상태다. 시안의 숫자·증감률·효과 배지를 복사하지 않는다.
- 종목 신청 현황은 기존 로더의 전국 부분 적재 결과임을 해당 차트에서 명시한다. 현재 지역 필터에 종속된 통계로 오인하지 않도록 별도 범위 안내를 둔다.
- CSV 다운로드 구현을 XLSX로 표기하지 않는다. 상단 대시보드의 관련 없는 시설 CSV 다운로드는 제거하고 선택 지역 프로그램 이동을 제공한다.
- 시설명 검색을 안정 ID로 연결된 강좌 분석처럼 표현하지 않는다. 연결 정보 미검증 상태를 상세에 표시한다.
- 작동하지 않는 탭·필터·내보내기 버튼이나 장식용 페이지 번호는 추가하지 않는다.

## 함께 보완한 동작

기존 필터 API를 재사용해 검색 조건을 왼쪽 폼에 노출한다. 프로그램·시설 목록에 Django Paginator를 적용한다. 페이지 이동은 TOP 3·요약·다운로드 모집단을 바꾸지 않는다. 시설 선택과 페이지 이동 시 지역·검색어를 유지한다. 프로그램 다운로드 URL에는 모든 적용 필터·정렬이 전달된다.

## 검증 결과 및 한계

- Django check 통과, 테스트 12개 통과, Python compileall 성공.
- 실제 CSV로 대시보드, 프로그램, 프로그램 2페이지, 시설, 시설 상세, 시설 2페이지가 모두 HTTP 200.
- 회귀 검증: 페이지 이동 시 TOP 3 및 적용 필터 보존, 시설 선택과 원본 HTML 문자열 이스케이프, 수급인원 0/결측 구분.
- CUA 상태 조회에서 apps/browsers가 모두 빈 배열이었다. 실제 브라우저 렌더링, 스크린샷, 1440×900·1280×800·모바일 뷰포트의 시각 검증은 미실행이다. 이 문서는 템플릿·스타일 구현과 서버 검증 결과이며 픽셀 단위 일치를 보증하지 않는다.
