# 결정 기록

## 2026-09-11 — 사용자 요청에 따른 시안 전면 재구성

- 사용자 후속 지시에 따라 3개 화면 모두 재배치한다. 검토표는 `DESIGN-REVIEW.md`에 기록한다.
- `app.css`를 단일 레이아웃 스타일로 다시 작성하고 중복 `shell.css`를 제거한다. 원본 `sport-insight-colors.css`는 유지한다.
- 외부 아이콘·폰트·이미지 의존성 없이 공통 SVG 심볼을 사용한다. 지도와 사진은 데이터가 없는 상태로 표시한다.
- 프로그램·시설 표의 시안상 페이지 컨트롤은 Django Paginator로 실제 구현한다. 적용 결과 전체와 화면 페이지를 분리한다.
- 프로그램 다운로드는 모든 검색 조건을 전달하도록 보완한다. 실제 파일 형식에 맞춰 CSV로 표시하고 XLSX 구현 완료로 표현하지 않는다.
- 브라우저 연결 부재로 화면 캡처와 실제 뷰포트 QA는 미실행임을 기록한다.

## 2026-09-11 — 시작 범위와 기존 구현 보존

- 사용자가 제공한 ZIP의 `prompts/CODEX-START.md`가 지정한 `00-bootstrap.md`만 구현한다. 기존 `_prompt/sport-insight-codex/prompts/START.md`도 동일 범위를 지정한다.
- Django 6.1.1과 기존 템플릿·데이터 서비스·CSV 다운로드를 유지한다. React 전환이나 새로운 패키지 설치는 하지 않는다.
- `/`는 데이터를 직접 렌더링하던 동작에서 `/dashboard`로 302 이동하도록 바꾼다. 회귀 테스트로 조회 함수를 실행하지 않는지 확인한다.
- 메뉴의 공지사항·설정을 제거하고 활성 메뉴에 `aria-current=page`를 적용한다. 기존 관리자 URL은 주 메뉴와 무관한 기존 개발 설정으로 유지한다.
- 제공된 색상 파일을 변경 없이 복사하고 기존 CSS의 공통 색상 변수를 연결한다. `shell.css`에서 접근성·크기·반응형 배치를 보완한다. 외부 웹폰트 요청은 제거한다.
- 원본이 실제 제공됐으므로 '원본 없음'으로 표기하지 않는다. 실제 자료 모드·부분 적재·기준시점 검증 상태를 공통 안내에 명시한다. 시연 데이터나 모드 전환 기능을 새로 만들지 않는다.
- 전체 CSV 구조 점검은 메타데이터만 기록한다. 따옴표 오류 파일은 엄격 파서 오류와 관대한 파서 기준 행 수를 함께 기록하며 원본은 수정하지 않는다.
- 데이터 집계 오류·안정 ID·전체 적재·정렬·엑셀 다운로드의 기존 한계는 단계01 이후 작업으로 남기며 현재 단계에서 완료로 선언하지 않는다.
