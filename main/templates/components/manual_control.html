스포링 GUIDE

서비스 이용 가이드

01

스포링 시작하기

서울의 체육복지 데이터와 AI 종합 분석을 통해 지역에 맞는 프로그램을 기획하고 운영안을 결정합니다.

STEP 1

목적에 맞는 화면 선택

새 프로그램을 구성하려면 프로그램 설계, 등록 강좌를 찾으려면 프로그램 현황, 시설 정보를 확인하려면 시설 현황을 선택합니다.

STEP 2

검색 조건 적용

지역과 필요한 조건을 선택한 뒤 조회 버튼을 누릅니다. 초기화를 누르면 해당 화면의 기본 조건으로 돌아갑니다.

STEP 3

결과 확인과 활용

지도, 요약 수치, 비교표와 상세 정보를 함께 확인하고 필요한 결과는 엑셀로 내려받습니다.

제목 옆 느낌표 아이콘에 마우스를 올리거나 초점을 이동하면 해당 지표와 집계 기준을 확인할 수 있습니다.

주요 정책 보기

화면 상단의 주요 정책 보기를 누르면 안내창이 먼저 열리고 정보를 불러옵니다. 수집된 정책은 최대 10건 표시되며, 항목을 누르면 원문이 새 창에서 열립니다. 조회 실패 시 안내를 확인하고 잠시 후 다시 시도해 주세요.

02

프로그램 설계

지역 이용현황을 확인하고 종목, 시설, 운영 조건을 순서대로 구성합니다.

  1. STEP 01 지역 선택과 AI 분석

    지도 또는 자치구 버튼으로 지역을 선택한 뒤 조회를 누릅니다. 시설·강좌·신청 실적과 종목 분포를 확인하고 AI로 분석하기를 눌러 지역 특징을 살펴봅니다. 분석 완료 후 같은 조회 상태에서는 재분석 버튼이 비활성화됩니다. 지역을 바꿔 조회하면 이전 결과는 참고용으로 유지되며 다시 분석할 수 있습니다.

  2. STEP 02 종목과 시설 선택

    종목을 선택하고 시설명이나 주소로 후보를 검색합니다. 상세 정보를 확인해 계획서에 포함할 시설을 최대 20곳 선택합니다. 매칭되는 후보가 없는 경우에만 시설 미정 진행에 동의한 뒤 다음 단계로 이동할 수 있습니다.

  3. STEP 03 프로그램 정보 입력

    프로그램명, 시설별 모집인원, 1인 수강료와 기준, 대상, 운영 시작일·종료일, 프로그램 설명을 입력합니다. 무료 프로그램은 수강료를 0으로 입력하며 금액은 천 단위 쉼표로 표시됩니다.

  4. AI 종합 검토와 계획서 완성

    AI로 분석하기를 누르면 화면 안에 진행 상태와 검토 결과가 표시됩니다. 지역 통계·선택 시설·운영안을 함께 검토하고, 결과를 계획서에 넣으려면 해당 내용을 보고서에 포함합니다를 선택합니다. 현재 입력에 유효한 AI 분석이 있거나 AI 분석 없이 계획서 생성을 선택하면 계획서 완성하기를 사용할 수 있습니다.

    같은 입력의 유효한 분석은 다시 요청할 수 없습니다. 입력을 바꾸면 기존 결과는 남지만 계획서 포함 선택이 해제되므로 새 내용으로 다시 분석해 주세요. 분석 실패 시 안내를 확인하고 다시 시도하거나 AI 없이 생성할 수 있습니다.

  5. 미리보기·인쇄와 처음으로

    계획서 완성하기를 누르면 미리보기가 열리고 프린트로 인쇄할 수 있습니다. 창을 닫아도 STEP 03은 유지됩니다. 처음으로를 누르면 선택·입력과 화면의 AI 분석을 초기화하고 STEP 01 최상단으로 이동합니다.

최근 생성 목록

프로그램 설계 제목 오른쪽의 최근 생성 목록 아이콘에서 이 브라우저에 보관된 최근 5건을 확인합니다. 다시 열기는 현재 설계 단계를 바꾸지 않고 생성 당시 계획서를 복원하며 AI를 다시 호출하지 않습니다. 개별 삭제와 전체 삭제가 가능하고, 브라우저 저장소를 지우면 목록도 사라집니다.

문자·카카오톡 버튼은 공유 내용을 확인하는 기능이며 실제 발송은 지원하지 않습니다. AI 분석은 재시도 시 수 분이 걸릴 수 있습니다.
03

프로그램 현황

서울의 자치구와 종목별 등록 강좌를 검색하고 비교합니다.

검색 조건

지역, 종목, 요일, 강좌명, 시설명, 정렬 기준과 예산 범위를 조합해 조회합니다.

요일 선택 기준

요일 하나를 선택하면 그 요일이 포함된 강좌를 찾고, 둘 이상 선택하면 선택한 요일 구성과 일치하는 강좌를 찾습니다.

추천과 지도

조건에 맞는 상위 프로그램과 자치구별 프로그램 건수를 확인합니다. 지도 색상은 프로그램 건수이며 시설 수가 아닙니다.

비교표와 내보내기

중복 제거된 강좌를 페이지별로 비교합니다. 엑셀 내보내기는 현재 검색 조건이 적용된 전체 결과를 저장하며, 50,000행을 넘으면 조건을 좁혀 다시 조회해야 합니다.

04

시설 현황

서울 자치구별 체육시설을 검색하고 시설 상세 정보와 인접 교통을 확인합니다.

시설 검색

지역, 종목 및 시설 유형, 시설구분, 운영상태, 보유주체, 시설명과 주소를 조건으로 조회합니다.

운영상태

기본 조회는 정상 운영 시설을 대상으로 합니다. 운영상태를 변경하면 휴업 또는 폐업 자료도 확인할 수 있습니다.

시설 상세

목록에서 시설명을 선택하면 주소, 연락처, 담당부서, 규모와 연결된 프로그램 정보를 확인할 수 있습니다.

인접 대중교통

시설 좌표와 교통 자료가 연결된 경우 가까운 버스정류장과 지하철역, 도보 정보를 확인할 수 있습니다.

05

데이터 최신화 관리

원본 CSV에서 서울 운영 데이터를 다시 만들고 서비스 반영 상태를 확인합니다.

  1. 최신화 실행

    지금 최신화를 누르면 서버에 있는 원본 CSV로 서울 데이터를 다시 정제합니다. 실행 중에는 진행 상태와 로그를 자동으로 확인하며 완료 또는 실패 안내를 확인해야 합니다. 제공기관에서 새 원본을 다운로드하는 기능은 아닙니다.

  2. 변경 사항 확인

    데이터 세대, 생성 시각, 원본 및 반영 행과 지역 코드 품질 검증 결과를 표에서 확인합니다.

  3. 서비스 반영과 오류 확인

    배치 성공 후 각 웹 프로세스가 새 데이터 세대를 감지해 캐시를 갱신합니다. 원본 파일이 없으면 안내창의 누락 파일과 로그를 확인한 뒤 서버에 원본을 준비해야 합니다. 기존 정상 캐시가 있으면 이를 이용할 수 있지만 최신 자료가 반영되었다는 의미는 아닙니다.

정기 배치는 매월 1일 01:00(Asia/Seoul)에 원본 변경 여부를 확인합니다. 원본과 서비스 파일 상태에 변경이 없으면 재정제를 생략하며, 서버가 중지된 동안의 예약 실행은 보장되지 않습니다.

로그 초기화는 최근 로그만 비웁니다. 생성된 CSV, 변경 사항 내역과 실행 상태는 삭제하지 않습니다.
06

데이터를 읽는 기준

화면 수치는 원본 자료의 제공 범위와 정제 기준에 따라 해석해야 합니다.

원본 행
전국 단위 원본 CSV에서 읽은 전체 데이터 행입니다.
반영 행
지역 코드 품질 검사를 통과하고 서울 데이터로 판정되어 서비스 CSV에 저장된 행입니다.
제외 행
코드 누락, 형식 오류, 시도와 시군구 코드 불일치로 정제 과정에서 제외된 행입니다.
프로그램 중복
프로그램명, 시설, 지역, 종목, 요일과 수강료가 모두 같은 결과는 비교표에서 한 건으로 표시합니다.
지도 색상
검색된 데이터의 지역별 건수를 표현합니다. 실제 이용 가능 여부나 시설의 실시간 운영 상태를 의미하지 않습니다.
신청 실적과 AI 평가
신청 실적은 자료에 수록된 기록의 합계이며 고유 이용자 수나 지역 전체 수요가 아닙니다. AI는 제공된 근거로 지역 현황과 프로그램·시설 적합성을 검토하고, 자료가 부족한 항목은 평가에서 제외하거나 판단 한계를 안내합니다.
