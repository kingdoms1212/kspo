자료 범위·검증 상태 확인

현재 화면은 data/의 CSV를 직접 읽습니다. 자료 기준시점·중복·시설 연계 검증이 완료되지 않았으므로 확정 통계로 사용하기 전 확인이 필요합니다.

  • 대시보드: 스포츠강좌이용권 이용현황 전수. 지원대상·수급인원 원본이 없어 수혜율은 계산하지 않습니다.
  • 프로그램: 공공체육시설 프로그램 정보 전수. 표시 항목이 모두 같은 중복 행을 제외한 건수입니다.
  • 시설: 전국공공체육시설 데이터 중 삭제 표시되지 않은 행. 장애인 시설 자료는 제공되지 않았습니다.
  • 연계: 시설↔프로그램은 시도·시군구 코드와 시설명·도로명주소가 모두 일치할 때만 연결합니다. 화면 간 지역명 표기는 자료마다 달라 대응표가 없습니다.
  • 지도: 행정경계 데이터 미연결. 제공되지 않은 값은 시연 데이터로 보충하지 않습니다.
