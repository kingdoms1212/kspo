# SPORT INSIGHT — Codex 전용 개발 패키지
버전: 1.1 / 분리일: 2026-09-11

## 이 패키지로 하는 일
마지막으로 확정한 **대시보드 / 프로그램 분석 / 시설 현황** 3개 화면을 개발하기 위한
Codex 단독 사용용 명세·프롬프트 묶음이다.
기존 제품 기능 명세는 유지하고 지침·시작 프롬프트·단계 프롬프트만 이 도구용으로 분리했다.

**완성된 앱이나 실행 프로젝트가 아니다.**
공공데이터 원본 CSV·JSON, 실제 운영 데이터, 대한민국 행정경계 GeoJSON은 포함하지 않는다.
아직 실제 앱을 실행하거나 앱 테스트를 통과한 상태라고 해석하지 않는다.

## 사용 순서
1. ZIP을 임시 폴더에 먼저 풀어 파일 구성을 확인한다.
2. 신규 저장소는 내부 파일을 프로젝트 루트에 배치한다.
   기존 저장소는 `AGENTS.md`, README, docs, contracts, design 등 충돌 파일을
   덮어쓰지 말고 백업·비교 후 필요한 내용만 병합한다.
   ZIP 바깥 폴더가 아니라 `AGENTS.md`가 놓인 프로젝트 루트를 작업 대상으로 연다.
3. `AGENTS.md`와 `docs/00-scope.md`, `docs/01-screen-spec.md`를 확인한다.
4. Codex에 `prompts/START.md`의 내용을 첫 메시지로 붙여 넣는다.
   지침을 새로 배치했으면 새 작업/세션에서 시작한다.
5. 이후 아래 단계를 한 번에 하나씩 실행하고 각 단계의 변경·검증 결과를 확인한다.
6. 기존 구현을 이어갈 때는 `prompts/RESUME.md`의 단계 경로만 바꿔 사용한다.
7. 코드 검토만 필요할 때는 `prompts/REVIEW.md`를 사용한다.

`AGENTS.md`에 공통 규칙을 직접 넣었다. 별도 공유 지침 import는 필요하지 않다.
프롬프트 파일은 지시문이다. 파일이 있다는 이유로 전체 단계가 자동 실행되는 구성은 아니다.
상세 명세를 저장소에 배치하지 않고 프롬프트만 실행하면 필요한 데이터 규칙이 빠질 수 있다.

## 바뀌지 않는 제품 범위
- 공공기관 담당자용 B2G 화면이며 시민용 예약·운동처방 앱이 아니다.
- 대시보드는 마지막 시안, 프로그램·시설 화면은 이전 카드·목록/상세 배치를 따른다.
- 추천은 실재하는 강좌의 조건 검색·정렬·상위 3개다. 새 강좌·숫자를 생성하지 않는다.
- 제품 AI API·추천 근거·인사이트·점수·효과 예측은 제외한다.
- 보고서 메뉴 대신 대시보드·차트·프로그램표·시설목록·시설별 강좌표의 XLSX를 제공한다.
- 원본 가격 단위가 검증된 경우에만 월 수강료 × 계획인원 × 지원개월을 계산한다.
- 시연과 실제 데이터를 구분하고 결측을 0 또는 시연 수치로 바꾸지 않는다.
- 지도 자산이 없으면 지역 선택·대응표를 제공하고 지도 기능은 미연결로 기록한다.

## 기존 데이터 검증 상태
원본 CSV·JSON과 전체 컬럼 정의서가 없으므로 실제 컬럼·가격 단위·시설 결합키·통계 중복은
검증 대기다. 영문 필드명은 제안한 내부 스키마이며 원본 컬럼명이라고 가정하면 안 된다.
이 패키지의 제약을 제거하거나 가짜 값을 넣어 미연결 상태를 감추지 않는다.
