Render 배포 관련 질문과 답변

[사용자 질문]

해당 프로젝트 render서비스를 이용해서 배포할려고해

1. Build Command 는 pip install -r requirements.txt 맞는것으로 보여
2. Start Command 를 뭘로 설정해야될지 확인해줘
3. 프로젝트에서 도메인 및 주소 설정 확인해줘


[답변]

확인했습니다. Start Command는 아래가 맞지만, 현재 프로젝트에는 배포용 설정 보완이 필요합니다. 파일은 변경하지 않았습니다.

1. Build Command

requirements.txt가 저장소 루트가 아닌 main/ 안에 있습니다. 따라서 다음 구성을 권장합니다.

- Root Directory: 비워두기
- Build Command: pip install -r main/requirements.txt
- Start Command: gunicorn --chdir main main.wsgi:application --bind 0.0.0.0:$PORT

프로젝트가 저장소 루트의 data/, image/, fonts/, theme/도 사용하므로 Root Directory를 main으로 지정하면 안 됩니다. Render에서는 지정한 Root Directory 밖의 파일에 접근할 수 없습니다.
Render 공식 문서: https://render.com/docs/monorepo-support

2. Start Command 적용 전 필요한 설정

진입점은 main/main/wsgi.py:17의 main.wsgi:application입니다. 0.0.0.0:$PORT는 Render의 포트 연결 방식에 맞춘 설정입니다.
포트 설정 문서: https://render.com/docs/web-services#port-binding

다만 현재 main/requirements.txt에 gunicorn이 없어 먼저 의존성에 추가해야 합니다.

또한 CSS·JS·이미지 제공을 위해 다음 설정이 필요합니다.

- whitenoise 의존성과 미들웨어 추가
- STATIC_ROOT 지정
- Build Command에 python main/manage.py collectstatic --noinput 추가

이 작업을 적용한 뒤의 Build Command는 다음과 같습니다.
Render Django 배포 가이드: https://render.com/docs/deploy-django

pip install -r main/requirements.txt && python main/manage.py collectstatic --noinput

3. 도메인 및 주소 확인 결과

설정 파일은 main/main/settings.py:24입니다.

- ALLOWED_HOSTS
  현재 상태: localhost, 127.0.0.1, testserver
  배포 시 필요한 변경: 실제 Render 도메인 추가
- DEBUG
  현재 상태: True
  배포 시 필요한 변경: 운영에서는 False
- SECRET_KEY
  현재 상태: 코드에 고정
  배포 시 필요한 변경: 새 키를 환경변수에서 읽도록 변경
- CSRF_TRUSTED_ORIGINS
  현재 상태: 미설정
  배포 시 필요한 변경: 배포 HTTPS 주소를 반영
- SECURE_PROXY_SSL_HEADER
  현재 상태: 미설정
  배포 시 필요한 변경: 프록시 뒤에서 HTTPS를 인식하도록 설정

예를 들어 실제 발급 주소가 https://kspo-example.onrender.com이라면 다음 형태입니다.

ALLOWED_HOSTS = ["kspo-example.onrender.com"]
CSRF_TRUSTED_ORIGINS = ["https://kspo-example.onrender.com"]
SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")

ALLOWED_HOSTS에는 https://를 붙이지 않습니다. Render가 제공하는 RENDER_EXTERNAL_HOSTNAME을 읽도록 구현하면 발급 도메인을 자동 반영할 수 있습니다. 현재 코드는 해당 환경변수를 읽지 않으므로 Render에 환경변수만 입력해서는 적용되지 않습니다.

페이지 주소는 /dashboard, /programs, /facilities이며, / 접속 시 /dashboard로 이동합니다. 서비스 도메인은 별도로 고정되어 있지 않습니다.

추가로 배포를 막는 데이터 문제가 있습니다.

- 원본 CSV 4개는 현재 Git 미추적 상태이며, 화면에서 읽는 data/Batch/*.csv도 Git에서 제외되어 있습니다. 배포 환경에 CSV를 공급하고 생성하는 과정이 필요합니다.
- main/manage.py:9의 시작 배치와 주간 스케줄러는 runserver에서만 실행됩니다. 위 Gunicorn 명령으로 실행하면 데이터 자동 생성과 주간 갱신은 동작하지 않습니다.

따라서 현재 상태에서는 명령어 설정 외에 도메인 허용, 정적 파일 제공, CSV 준비 및 배치 실행 방식까지 보완해야 정상적으로 배포할 수 있습니다.
