Hi스포링 기능별 담당자 주석 목록
==============================

작성 기준
- 담당 코드는 기능 식별자이며 줄 단위 단독 저작권이나 기여율을 의미하지 않습니다.
- 같은 기능의 시작점에는 같은 코드를 사용하며, 공동 파일은 기능 블록별로 구분합니다.
- Git 변경 내역과 팀 내 확인 내용을 기준으로 주 담당자를 정리했습니다.
- AI 백엔드는 서정길, AI UI는 홍석환 담당으로 구분하고 후속 공동 기여를 별도로 기록합니다.
- 기존 [SG001], [SG003]은 예외처리 식별자이며 담당 코드와 별도로 유지합니다.
- 코드 위치와 함수명은 기록하지 않습니다. 대괄호를 포함한 담당 코드로 소스를 검색합니다.
- 원본 CSV, 외부 라이브러리와 생성 산출물에는 담당 주석을 추가하지 않습니다.
- 화면의 프론트 담당 표기는 해당 파일의 모든 요청·검증 로직을 단독 개발했다는 뜻이 아닙니다.
- URL은 현재 라우팅 기준이며, 화면·예약 작업은 연결 화면 또는 실행 시점을 함께 표시합니다.
